# District presets: sources (2026-27)

Owner: Agent R. Data: `src/content/schoolDistricts/` (one file per district). Presets as of **2026-11-04**.

Method: I found each calendar by web search, then read it from the district's own site, either the page itself or a PDF the district page links to. News and aggregator sites were used only to find links, never as the source of any date. A closure is a weekday between the first and last student day when students do not attend. Early-release days are not closures. Days a district may use for weather make-up are listed only when the calendar already shows them as a no-school day, and they are marked `weather-makeup-reserve`. Where the district states how many student days the year has, or its calendar has day counters, I checked that **weekdays minus closures** gives that number. Those checks are also unit tests in `index.test.ts`.

This is not a directory of every district. Families should check their own school's calendar.

## Excluded

- **Miami-Dade County Public Schools**: the official calendar PDF on api.dadeschools.net blocks automated reads, the www3 calendar page is script-only, and the board approval item has no dates.
- **Clark County (Las Vegas)**: no official ccsd.net 2026-27 calendar document found; only aggregator sites came up.
- **Hillsborough County (Tampa)**: the official page (hillsboroughschools.org/page/calendar26-27) is script-rendered, and no readable calendar file was found.
- **Orange County Public Schools (FL)**: the 2026-27 calendar page on ocps.net blocks automated reads, and the embedded calendar was empty.
- **Boston Public Schools**: the calendar is linked only as Google Drive files, which could not be read without signing in. The district page showed only November dates.
- **Wake County, Denver, San Diego Unified**: not finished. Stopped at 12 verified districts (quality over count). Denver has school-hosted copies of the district PDF on dpsk12.org that could be a next step.
